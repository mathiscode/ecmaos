# EcmaOS Modules

A kernel module is a file, `NAME.ko.mjs` (TypeScript or JavaScript, runs in the kernel) or `NAME.ko.wasm` (a sandboxed
WebAssembly component, for example from Rust). Make one with `turbo gen module`, and see the Modules section of the
[README](./README.md) for what a module can do and how `insmod`, `modprobe` and `install` load it.

## Official Modules
