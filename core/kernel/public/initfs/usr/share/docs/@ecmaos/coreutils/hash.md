# hash

`man @ecmaos/coreutils/hash`

## Synopsis

```
hash [OPTION]... [FILE]...
```

## Description

Compute and display hash values for files or standard input.

## Options

```
  -a, --algorithm=ALGORITHM  hash algorithm to use (sha1, sha256, sha384, sha512)
                              default: sha256
  --help                      display this help and exit
```
