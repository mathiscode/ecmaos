# tr

`man @ecmaos/kernel/commands/tr`

## Synopsis

```
tr [OPTION]... SET1 [SET2]
```

## Description

Translate or delete characters.

## Options

```
  -d, --delete    delete characters in SET1
  -s, --squeeze   replace each sequence of a repeated character
  --help          display this help and exit
```
