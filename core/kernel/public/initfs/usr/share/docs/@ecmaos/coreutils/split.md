# split

`man @ecmaos/coreutils/split`

## Synopsis

```
split [OPTION]... [INPUT [PREFIX]]
```

## Description

Split INPUT into fixed-size pieces.

## Options

```
  -l, -lNUMBER        put NUMBER lines per output file
  -b, -bSIZE            put SIZE bytes per output file
  --help                 display this help and exit
```
