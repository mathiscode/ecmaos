binfmt

  • binfmt(spec: BinfmtSpec): void

  • Teaches execve a program format, as binfmt_misc does: a file matches recognizes is run as interpreter FILE ARGS. It is tried after the formats for #! scripts and WebAssembly, which are exact, and before the one for JavaScript, which takes any text file. Fails with EEXIST if the name is taken. Removed when the module unloads.

syscallPolicy

  • syscallPolicy(
        policy: (
            call: { exe?: string; pid: number; syscall: string; uid: number },
        ) => boolean | void,
    ): void

  • Adds a check to every syscall a process makes: when policy returns false the syscall fails with EPERM. It can only deny, and a policy that throws is logged and ignored, so a broken one cannot lock the machine. Removed when the module unloads.
