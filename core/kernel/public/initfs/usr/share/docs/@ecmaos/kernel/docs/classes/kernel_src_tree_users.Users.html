resetPassword

  • resetPassword(uid: number, newPassword: string): Promise<void>

    An administrator sets a password without knowing the old one. The hash and /etc/shadow are rewritten, and a lock is lifted. The private key in ~/.ssh stays encrypted under the old password, so it can no longer be unlocked, as with an encrypted home directory on Linux; nothing at login needs it.
