Interface ShellBuiltinIO

The three standard descriptors as a builtin sees them, so a builtin honors redirections and works in pipelines. A direct terminal implementation serves a lone builtin with nothing redirected; a stream-backed one serves the rest. Text-shaped: encoding happens in one place.
