# sleep

`man @ecmaos/coreutils/sleep`

## Synopsis

```
sleep NUMBER[SUFFIX]...
```

## Description

Pause for NUMBER seconds.  SUFFIX may be 's' for seconds (the default), 'm' for minutes, 'h' for hours or 'd' for days.

## Options

```
  --help  display this help and exit
```
