# fgrep

`man @ecmaos/kernel/commands/fgrep`

## Synopsis

```
fgrep [OPTION]... STRING [FILE]...
```

## Description

`grep -F`: searches for a fixed string. It runs `grep` with the same arguments.

## Exit status

That of `grep`.
