# b2sum

`man @ecmaos/coreutils/b2sum`

## Synopsis

```
b2sum [-c] [--tag] [FILE]...
```

## Description

Print or check BLAKE2b-512 checksums, the same way `sha256sum` does for SHA-256.

## Options

```
  -c, --check  read sums from FILEs and check them
      --tag    BSD-style output
      --quiet, --status, -b, -t, -w  as for sha256sum
```

## See also

`sha256sum`, `md5sum`
