# gunzip

`man @ecmaos/coreutils/gunzip`

## Synopsis

```
gunzip [OPTION]... [FILE]...
```

## Description

Decompresses each FILE.gz and removes the `.gz`; with no FILE it decompresses standard input. The options are `gzip`'s.

## Exit status

As for `gzip`.
