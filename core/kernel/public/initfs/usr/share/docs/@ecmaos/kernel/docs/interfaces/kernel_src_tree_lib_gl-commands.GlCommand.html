Optionalreply

reply?: "i" | "s" | "v" | "f" | "p" | "a"

The command is a question: its answer is kept for the program to fetch with GL_REPLY, in this form: i one signed word, s a byte count and then the text, v a word count and then signed words, f the same as floats, p the bytes themselves (for readPixels), a a size word, a type word and then text as s. A question that fails is answered with zeros, so a program never waits for nothing
