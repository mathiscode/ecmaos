# rev

`man @ecmaos/coreutils/rev`

## Synopsis

```
rev [options] [file ...]
```

## Description

Reverse lines characterwise. With no file, or when file is -, read standard input.

## Options

```
  -0, --zero   use the NUL byte as line separator
  -h, --help   display this help and exit
```
