Class RemoteFS

Another ecmaOS machine's directory, mounted here. The synchronous file API is served from an in-memory copy of the remote tree (Async copies it when the mount is made and sends changes on in the background), so a tree past limits is refused, changes made on the other machine are not seen until remounted, and a change refused over there is reported through onError. The asynchronous API (fs.promises) reaches the other machine.
