# lscpu

`man @ecmaos/coreutils/lscpu`

## Synopsis

```
lscpu
```

## Description

Show the processor information the browser reports: the number of logical processors and the platform string. A browser does not say the processor's model, speed or caches, so those lines are left out rather than guessed.

## Options

```
  --help  display this help and exit
```
