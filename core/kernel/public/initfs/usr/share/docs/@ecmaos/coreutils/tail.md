# tail

`man @ecmaos/coreutils/tail`

## Synopsis

```
tail [OPTION]... [FILE]...
```

## Description

Print the last 10 lines of each FILE to standard output.

## Options

```
  -n, -nNUMBER        print the last NUMBER lines instead of 10
  --help             display this help and exit
```

## See also

`tail --help`
