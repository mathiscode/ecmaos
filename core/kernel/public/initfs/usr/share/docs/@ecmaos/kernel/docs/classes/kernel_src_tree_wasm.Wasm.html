Class Wasm

Plain wasm32-wasip1 modules and ordinary emcc builds run as worker processes under /bin/wali (see canRunInWorker). What still runs here (real internet sockets, an unimplemented __syscall_*, preview2 components) calls _start on the main thread with no yield point unless built with asyncify, so an infinite loop freezes the tab and ^C cannot reach it.
