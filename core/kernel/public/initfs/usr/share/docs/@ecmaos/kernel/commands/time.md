# time

`man @ecmaos/kernel/commands/time`

## Synopsis

```
time COMMAND [ARG]...
```

## Description

Run COMMAND and print a summary of the real, user, and system time used.

## Options

```
  --help  display this help and exit

Note: This is a simplified version that measures real (wall clock) time.
```

## See also

`time --help`
