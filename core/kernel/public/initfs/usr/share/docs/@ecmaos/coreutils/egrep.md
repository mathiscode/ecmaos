# egrep

`man @ecmaos/coreutils/egrep`

## Synopsis

```
egrep [OPTION]... PATTERN [FILE]...
```

## Description

`grep -E`: searches with an extended regular expression. It runs `grep` with the same arguments.

## Exit status

That of `grep`.
