# expand

`man @ecmaos/coreutils/expand`

## Synopsis

```
expand [OPTION]... [FILE]...
```

## Description

Convert tabs to spaces in each FILE.

## Options

```
  -t, --tabs=NUMBER     have tabs NUMBER characters apart, not 8
  -t, --tabs=LIST       use comma separated list of tab positions
  --help               display this help and exit
```
