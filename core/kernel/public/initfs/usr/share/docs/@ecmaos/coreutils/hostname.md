# hostname

`man @ecmaos/coreutils/hostname`

## Synopsis

```
hostname [OPTION]
```

## Description

Print the system hostname.

## Options

```
  -f, --fqdn              print the FQDN (Fully Qualified Domain Name)
  -s, --short             print the short hostname
  --help                  display this help and exit
```

## See also

`hostname --help`
