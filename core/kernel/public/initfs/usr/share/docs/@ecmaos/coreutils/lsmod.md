# lsmod

`man @ecmaos/coreutils/lsmod`

## Synopsis

```
lsmod
```

## Description

Lists the kernel modules that are loaded, from toybox 0.8.12, read from `/proc/modules`. These are the drivers the kernel has registered (`tty`, `webstorage`, and the devices that have been added); their size is not known to the kernel and reads 0.
