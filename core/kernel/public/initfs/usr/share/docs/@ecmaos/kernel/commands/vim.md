# vim

`man @ecmaos/kernel/commands/vim`

## Synopsis

```
vim [OPTION]... [FILE]...
```

## Description

Vi IMproved - a text editor.

## Options

```
  FILE                    file(s) to edit
  --help, -h              display this help and exit

Examples:
  vim file.txt            edit file.txt
  vim file1.txt file2.txt edit multiple files
```
