# fastfetch

`man @ecmaos/coreutils/fastfetch`

## Synopsis

```
fastfetch [--no-color] [--no-logo]
neofetch
```

## Description

Print a logo and a summary of the system: the operating system and version, the kernel, uptime, shell, terminal, processors, memory, browser and platform. A line whose value is not known is left out. `neofetch` is a link to the same program.

## Options

```
  --no-color  no colors, even on a terminal
  --no-logo   print the facts only
  --help      display this help and exit
```
