Interface ShadowEntry

/etc/shadow: name:hash:lastchg:min:max:warn:inactive:expire:reserved, as in shadow(5). hash is $id$params$salt$hash; a leading ! locks the account, * means no password can log in, empty means no password. lastchg and expire are days since 1970-01-01. Other fields are optional; fields past the ninth and # comments are kept on rewrite.
