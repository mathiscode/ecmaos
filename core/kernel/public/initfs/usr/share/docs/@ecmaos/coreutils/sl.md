# sl

`man @ecmaos/coreutils/sl`

## Synopsis

```
sl [-a] [-l] [-F] [-c]
```

## Description

sl 5.02: a steam locomotive crosses the terminal, for those who type `sl` when they mean `ls`. `-a` adds an accident (people calling for help), `-l` draws a little one, `-F` makes it fly and `-c` brings the C51 instead of the D51. As on Linux, `^C` does not stop it; it stops when it has passed.
