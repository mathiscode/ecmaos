Interface KernelDevice

Interface representing a kernel device. This essentially "wraps" one or many @zenfs/linux character devices and provides metadata and a CLI interface for it.

OptionalgetTTYDrivers

  • getTTYDrivers?(ctx: KernelContext): Promise<TTYDriver[]>

    Terminal drivers this package registers: @zenfs/linux TTYDrivers, for devices that are terminals on Linux (serial ports). The kernel registers each one's device numbers and tells it the first open and the last close of a line, as it does for getDrivers' devices. The package adds and removes lines itself (driver.line(n).register()), as devices come and go.
