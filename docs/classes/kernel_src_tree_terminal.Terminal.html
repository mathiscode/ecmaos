attachInput

  • attachInput(): () => void
  • Experimental

    Feeds raw input (onData) into this terminal's @zenfs/linux TTY so a foreground program reading fd 0 gets line-discipline input (canonical/raw mode, echo, ISIG). While held, keyHandler stands down. Reference- counted; returns an idempotent release. The last release hands unread typeahead back to the line editor. Mobile does not use it.

    Returns () => void

    Implementation of ITerminal.attachInput
