script

  • script(
        kernel: Kernel,
        path: string,
        args: string[],
        run: () => Promise<number>,
    ): number

  • Runs a kernel-shell script as a child of init: a Process that exits with the script's status, so init reaps it and waits for it like any other entry. It has no thread and no program loaded; run does the work on the main thread, where the shell lives.
