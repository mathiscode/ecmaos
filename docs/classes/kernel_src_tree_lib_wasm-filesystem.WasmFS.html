Readonlylazy

lazy: boolean

-o lazy (or lazy=true) keeps no copy of the tree: nothing is read at mount, every call goes to the module, and the synchronous calls, which need a copy, fail with ENOTSUP. For a tree too big to hold in memory, or too slow to walk.
