Class PopupRenderer

An optional, seamless mode: each window is a separate browser popup, so the operating system's window manager places it, instead of a box drawn inside the page. The popup's content is an element of the page moved into the popup's document, so DOM windows work unchanged. A popup needs a user gesture: when the browser refuses it (or a popup is closed by the user while the machine wants to keep the window) the window is drawn by fallback instead, with its content moved there.
