Interface ProgramEntry

Prebuilt WebAssembly programs (vim, jq, make, ...), published by @ecmaos/coreutils and @ecmaos/coreutils- copyleft and served as a catalog at /programs/index.json. Boot writes /bin/<name> for any program whose installed copy differs from the catalog.
