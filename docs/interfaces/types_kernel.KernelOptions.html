Optionallimits

limits?: { maxFileBytes?: number | false; warnResidentBytes?: number | false }

Limits for the IndexedDB root, which is held whole in memory: the most one file may hold (EFBIG past it) and the total in memory that logs a warning. Both default from the device's memory (512 MiB and 1 GiB on an 8 GB machine or better); false turns one off.

Optionalmodules

modules?: string | false

Where the catalog of in-tree kernel modules is (default /modules/index.json); false fetches none. The modules zip, iso, dropbox and googledrive are in it, and are downloaded the first time mount -t asks for one.

  • Defined in core/types/kernel.ts:333

Optionalprofile

profile?: "standard" | "minimal" | "developer" | "everything"

Which programs of the catalog a first boot installs: minimal, standard, developer or everything (also ?profile= and ECMAOS_PROFILE). It is not recorded. Without it a machine that already has programs is Everything, a headless boot is Standard, and a browser asks once (see /etc/ecmaos/profile).

  • Defined in core/types/kernel.ts:328

Optionalprograms

programs?: string | false

Where the catalog of prebuilt WebAssembly programs is (default /programs/index.json); false installs none. See @ecmaos/coreutils and @ecmaos/coreutils-copyleft, which supply the programs.
