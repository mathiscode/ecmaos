OptionaldrainStdout

drainStdout?: boolean

Whether this stage's stdout must be fully drained before its exit code is reported. True for a final destination (a file or the terminal) so cmd > f leaves every byte in f; false mid-pipeline, where an early- exiting downstream program would leave the drain waiting forever.

Optionalforeground

foreground?: boolean

Whether this stage belongs to the foreground job (default true). A backgrounded (&) stage passes false so it does not take the terminal. Kernel.executeViaExecve sets the TTY's foreground to the process while it runs and restores it afterwards.

OptionalstderrIsTTY

stderrIsTTY?: boolean

Whether stderr is the terminal itself (no 2> or 2>&1 on the command), so the program is left its descriptor 2 on the console and isatty(2) holds, as it does on Linux. stderr is then only for what is not a process.
