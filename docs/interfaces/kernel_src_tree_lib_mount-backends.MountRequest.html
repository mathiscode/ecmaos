Interface MountRequest

Everything mount needs that only the main thread has: the live kernel.filesystem mount table, the browser storage/File System Access APIs, and Google's OAuth scripts (injected into document.head). The mount program itself (bin/commands/mount.mjs) is a thin argument parser that reaches this through the fs_mount syscall; the backend logic below is the original mount command body, moved rather than rewritten.

Results come back as lines for the program to print ({ stream, text }) plus an exit code, since a syscall can only return a number and the messages are the whole user-visible output.
