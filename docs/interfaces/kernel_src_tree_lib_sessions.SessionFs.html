Interface SessionFs

Who is logged in and who has been: /run/utmp and /var/log/wtmp, text with tab-separated records, read by who and last.

  • /run/utmp: user<TAB>ttyN<TAB>epoch-ms, one line per console with a login now. Emptied at boot.
  • /var/log/wtmp: login<TAB>user<TAB>ttyN<TAB>epoch-ms per login and boot<TAB>~<TAB>system boot<TAB>epoch-ms per boot. There is no logout record; last ends a session at the next boot line. Written as root, since users must not edit wtmp.
