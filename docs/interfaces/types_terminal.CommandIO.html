Interface CommandIO

Minimal per-invocation I/O handed to a coreutils command, replacing the old pattern of manually resolving process and threading it plus terminal through writelnStdout/writelnStderr on every call. stdout/stderr/stdin stay available as raw streams for commands that need byte-level control (e.g. cat's getWriter()/getReader() usage) -- this is deliberately a thin wrapper, not a replacement for direct stream access.

interface CommandIO {

}
